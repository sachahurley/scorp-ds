# Scorp DS component references (consumer / agent)

**`catalog.md`** is the reference: every component, what it is for, what to use
instead, how to import it, and every prop with the values it accepts.
~~Struck-through~~ values and props are deprecated.

It is generated by `scripts/generate-catalog.mjs` from
`docs/contracts/api-surface.json` (itself generated from the component source)
and the specs in `docs/specs/`. Do not edit it by hand; CI fails when it is stale.
It replaces the hand-maintained `Scorp-button.md` and `Scorp-stack.md`, which had
drifted from the code (they taught the deprecated `size="medium"`).

## Sync into a consumer project

From the consumer's root, after pulling the latest Scorp DS:

```bash
mkdir -p docs/scorp-ds-refs
rsync -a --delete /path/to/scorp-ds/docs/component-references/ docs/scorp-ds-refs/
```

Point the consumer's agent rules at `docs/scorp-ds-refs/catalog.md`.
