## Intent

<!-- HUMAN-SECTION:intent -- This section is preserved across auto-updates -->

Text input with a filtered listbox for choosing one option from a long list. WAI-ARIA 1.2 combobox with list autocomplete: focus stays in the input, the highlighted option is conveyed with aria-activedescendant. Built on Popover positioning, so the list flips above the field near the viewport bottom and caps its height to the available room.

Keyboard: ArrowDown/ArrowUp open and move (wrapping, skipping disabled), Alt+ArrowDown opens without moving, Home/End jump while open, Enter picks, Escape closes (restoring the committed label) and clears when already closed, Tab closes without picking.

Use Select for short lists (under about 10 options).

<!-- /HUMAN-SECTION:intent -->
